# Project-1
This project assesses and defends web applications against common security threats. SQL Injection and XSS attacks will be performed on DVWA, followed by ModSecurity WAF configuration to block them. PrestaShop will also be assessed using a security checklist, followed by a controlled attack, mitigation, and retesting
